# snsf.oa.ror.zurich.26

<!-- badges: start -->

<!-- badges: end -->

The goal of `snsf.oa.ror.zurich.26` is to make available the code and
data to reproduce the results of an analysis presented at the [Research
on Research Event 2026](https://crsuzh.pages.uzh.ch/ror-event-2026/)
which was held on 29 January 2026 in Zürich, Switzerland. The event has
been organized by the [Center for Reproducible Science and Research
Synthesis](https://www.crs.uzh.ch/en.html).

Reference of the poster presentation: Gorin S. (2026, January 29).
*Monitoring open access publications at the SNSF: the challenges of open
academic data* \[Poster presentation\]. Research on Research Event 2026,
Zürcih, Switzerland. [https://crsuzh.pages.uzh.ch/ror-event-2026/]()

## Installation

You can install the development version of `snsf.oa.ror.zurich.26` like
so:

``` r
devtools::install_github("snsf-data/snsf.oa.ror.zurich.26")
```

## Example

The code to reproduce the analysis is available in the [“Monitoring open
access publications at the SNSF: the challenges of open academic data”
vignette](https://snsf-data.github.io/ERforResearch/articles/ror_presentation.html)
under the article section.
